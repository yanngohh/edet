## Default Permission

Default permissions for the conductor service plugin.

#### This default permission set includes the following:

- `allow-start-service`
- `allow-stop-service`
- `allow-request-battery-exemption`
- `allow-is-battery-optimized`
- `allow-is-shared-conductor-available`
